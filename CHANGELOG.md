# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/), and this
project adheres to [Semantic Versioning 2.0.0](https://semver.org/spec/v2.0.0.html).

Release entries are generated by `semantic-release` from Conventional Commits (see
[`docs/versioning.md`](docs/versioning.md)); the `VERSION` file and the root `pom.xml` version are
kept aligned manually.

## [Unreleased]

### Added

- Container build and signing pipeline: four multi-stage Dockerfiles, CycloneDX SBOMs as build
  artefacts and keyless `cosign` signatures (AC-8, AC-9, AC-10).
- CI/CD workflows: build + unit tests + lint on every push to `main`, dependency scanning (SCA),
  CodeQL (SAST), secret scanning, container images, release automation and PR title linting
  (AC-4 … AC-7, AC-11).
- Repository governance: `CODEOWNERS`, pull request template, issue templates, Dependabot,
  `VERSION`, this changelog and semantic-release configuration (AC-13).
- Local orchestration: `infra/docker-compose.yml` (PostgreSQL 16 + three services + frontend) and
  Kubernetes base manifests in `infra/k8s/base`.

### Security

- Secret scanning at two independent levels: `gitleaks` workflow plus a deterministic `grep` gate
  inside `ci.yml` (ADR-0010).
- No credential is stored in the repository: every value is read from the environment and
  documented as `__change_me__` placeholders in `.env.example` (AC-12).

## [0.1.0] - 2025-01-01

### Added

- Monorepo scaffolding with five top-level modules: `core-app`, `document-service`, `bff`,
  `frontend`, `infra` (AC-1).
- `core-app`: claim lifecycle (7-state machine) and policy read model, exposed through
  `/api/v1/claims` and `/api/v1/policies`; RFC 9457 problem details for every error.
- `document-service`: multipart document upload, metadata listing, content download and soft
  delete on `/api/v1/documents`.
- `bff`: aggregation layer on `/bff/v1/claims` and `/bff/v1/dashboard/summary`.
- `frontend`: React 18 + TypeScript + Vite single page application (claim list, claim detail,
  dashboard).
- PostgreSQL persistence owned by Flyway (`V1` migrations for schemas `coreapp` and `documents`),
  Hibernate in `ddl-auto=validate` mode (AC-12, `docs/db/README.md`).
- Shared build conventions in the root `pom.xml`: Java 21, Spring Boot 3.3.5, google-java-format
  via Spotless, Checkstyle, JaCoCo coverage report and the CycloneDX Maven plugin (AC-2).
- Frontend tooling: ESLint 9 flat config, Prettier 3, Vitest + Testing Library, strict TypeScript
  (AC-3).
- API contracts committed as reviewed OpenAPI snapshots in `docs/api/` (ADR-0009).
